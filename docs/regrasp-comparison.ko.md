# 편심과 저마찰에서의 재파지 비교

같은 50 g 셸을 사용했다. 편심 조건 16개는 패드 마찰 계수 0.8에서 X 오프셋을 바꿨다. 저마찰 조건 16개는 중심 근처 네 위치에서 마찰 계수 0.018, 0.033, 0.048, 0.063을 각각 시험했다. 편심은 첫 파지점과 물체 사이의 위치 오차를 뜻한다.

모든 조건에서 같은 첫 파지와 들기 경로를 실행했다. 물체를 내려놓고 턱을 연 상태를 저장한 뒤, 두 재파지를 같은 체크포인트에서 시작했다.

- **위치 보정**은 첫 파지와 같은 턱 명령으로 물체의 X 위치에 맞춰 경로를 이동한다. 이동량을 계산하기 위해 MuJoCo 상태를 읽으므로 위치 추정이나 촉각 정책 성능은 이 비교에서 측정하지 않는다.
- **그립 보강**은 첫 경로를 유지하고 턱당 닫힘 명령을 26.2 mm에서 33.5 mm로 늘린다. 이 값은 모터 위치 명령이다.
- **성공**은 마지막 0.24초 동안 8 mm 이상 들고 기울기 20° 이내에서 탁자 접촉 없이 버틴 경우다. 팔 구동기가 해당 구간에 계속 포화된 경우도 실패로 센다.

| 첫 파지가 실패한 조건 | 위치 보정 | 그립 보강 |
| --- | ---: | ---: |
| 편심 14개 | 14/14 | 5/14 |
| 저마찰 16개 | 0/16 | 12/16 |

편심 16개 중 2개는 첫 파지가 성공했다. 편심 실패 가운데 첫 프로브에서 양쪽 패드의 법선력이 동시에 0.15 N을 넘긴 여섯 조건만 보면 위치 보정 6/6, 그립 보강 5/6이었다. 저마찰 계수 0.018에서는 두 재파지가 네 조건 모두 실패했다. 이 값들은 결정적 시뮬레이션의 조건별 집계이며, 실물 성공률이나 자동 복구 정책의 성능은 후속 실험에서 평가한다.

## 실행과 재생

```sh
python -m pip install -r simulation/requirements.txt
python scripts/run_regrasp_comparison.py --output regrasp-comparison
python simulation/sim.py --port 8770
```

출력은 시행별 `trials.csv`, 프로토콜과 집계가 담긴 `summary.json`, 40 ms 간격의 관절·물체 자세 및 양쪽 77점 촉각 기록 `traces.jsonl.gz`다.

Fusion 360에서 내보낸 로컬 R7 상세 장면을 보유한 경우, 실험과 대시보드에서 같은 XML을 지정할 수 있다. XML과 같은 디렉터리에 장면이 참조하는 메시와 `object.xml`을 둔다. 대시보드의 **집기 확대** 카메라는 두 턱을 사선에서 보여준다.

```sh
python scripts/run_regrasp_comparison.py --scene /path/to/R7/scene.xml --output regrasp-fusion
python simulation/sim.py --scene /path/to/R7/scene.xml --port 8770
```

공개 장면의 랙·레일 등 여섯 부품은 렌더링용 단순 형상이다. 정측면에서는 두 턱이 화면상 겹친다. 상세 장면에서는 해당 부품을 CAD 메시로 표시하며, **집기 확대**를 선택하면 두 턱과 물체를 함께 볼 수 있다. 대시보드가 현재 불러온 메시 유형을 영상 아래에 표시한다.
