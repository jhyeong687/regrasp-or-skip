Regrasp or Skip? / Research

When should a gripper recenter or tighten?

When a grasp slips, the SO-ARM101 can reposition its jaws, close them further, or do both. We replay those choices from the same MuJoCo state to see which ones put the part in the tray.

Follow-up experiments

Look again after the jaws retract

After the first wrist image, the part can move and rotate. In 216 matched MuJoCo conditions, we kept the recovery motion and closing command fixed and changed when the same RGB-D camera supplied the target. A further 72 conditions tested different ways to update the grasp angle.

What touch adds to action selection

Adding tactile features to the same learned decision rule gained nine placements and lost one. When the two policies were assigned the same number of each action across the test batch, touch still gained 10 net placements. The batch comparison uses all observations together.

Matched replay

One test lift, four possible decisions

The simulator restores the robot and object state after a common 16 mm trial lift. Each branch then continues, recenters, reinforces, or recenters and reinforces. Placement is scored after the jaws release and the object settles.

Policy results

Where contact location changes the decision

Across the controlled and shape-transfer experiments, the combined action was the sole successful branch in 50 of 225 conditions. A policy that uses contact location alongside contact timing gained 12 placements on the main set and six on the shape-transfer set.

Moved-object experiment

The first camera estimate can expire

The object moves 0, 12 or 24 mm after the wrist camera estimates a grasp. A fixed oblique RGB-D view updates the position after the test lift. Every policy that recenters to an updated target uses the same new coordinate.

Recovery execution

The order of motions matters

Descending with closed, nearly empty jaws can push the object away from the next grasp. Opening first reduced median object drift from 20.548 mm to 0.002 mm in the gated main conditions. A separate 8 mm rise rescued seven of 15 failed direct carries.

Exploratory Astra comparison

GPT-6.2 Astra selected a successful branch in 21/24 paired cases with tactile summaries and 20/24 without them. These decisions were scored against the saved simulator branches. The three main experiments above use fixed decision rules, and all placement results come from simulation.
