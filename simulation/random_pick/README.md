# SO-ARM101 RGB-D 파지·운반 파일럿

작업대 위에 직육면체, 원기둥, 긴 직육면체를 각각 네 번씩 한 개씩 배치한다. 시드가 물체 순서와 작업영역 안의 x/y 및 평면 회전을 결정한다. 기존 R7 MuJoCo 장면과 메시를 그대로 읽고 이 실행기의 작업물과 트레이를 별도로 추가한다.

1. 손목 깊이와 같은 광학계에서 렌더한 색상으로 대상 표면을 마스킹한다. 195 mm 미만 등 센서 범위 밖의 깊이는 배제한다. 보정된 3D 표면에서 중심과 장축을 추정하고, 중심 및 양쪽 후보를 만든 뒤 실행 가능한 후보에 A/B/C를 무작위로 붙인다.
2. GPT-6.2 Astra `xhigh`가 좌우 및 손목 RGB와 손목 깊이 이미지, 관측치, IK 후보를 받고 한 가지 파지를 고른다. 호출마다 새 Codex 스레드를 열고 모델·추론 설정 및 원 응답을 저장한다. 모델이 파지를 거절하거나 호출에 실패하면 해당 회차의 결과로 기록한다.
3. 선택한 파지로 기존 IK와 MuJoCo 접촉·마찰을 사용해 접근, 닫기, 들어 올리기를 실행한다. 미리 정한 트레이 경로로 운반하고 그리퍼를 열고 후퇴한다. 그 후의 트레이 바닥 접촉, 중심 위치, 물체 속도, 그리퍼 열림 및 손가락 접촉 해제를 검사한다. 시뮬레이터의 실제 물체 위치는 스폰과 사후 평가에만 쓴다. 모의 PaXini 힘은 기록한다.

## 실행

Python에 `mujoco`, `numpy`, `pillow`가 필요하다. 기존 Codex CLI 로그인에서 해당 모델 설정을 사용할 수 있어야 한다. `--scene`에는 원래 R7 장면 XML과 옆에 필요한 메시가 있어야 한다. macOS 렌더러 메시지는 명령을 실행한 디렉터리에 생길 수 있다.

```sh
python /path/to/tactile-grasp-agent/simulation/random_pick/run.py \
  --scene /path/to/SO101_R7_Tactile_Demo/scene.xml \
  --out /path/to/new-run --seed 261126
```

같은 출력 디렉터리를 별도 프로세스에서 서빙하면, 실행 중과 완료 후에 대시보드를 볼 수 있다.

```sh
python /path/to/tactile-grasp-agent/simulation/random_pick/serve.py \
  --out /path/to/new-run --port 62653
```

[로컬 대시보드](http://127.0.0.1:62653/)에서 회차별 실제 경과 시간과 추론 시간을 확인하고 동작을 재생할 수 있다. `total_s`는 회차 초기화부터 물리 실행·채점·기본 로그 저장까지의 실제 경과 시간으로 모델 호출과 프레임 캡처를 포함한다. `inference_s`는 Codex 호출 시작부터 응답 수신까지의 경과 시간으로, 연결과 런타임 준비가 포함된다. `sim_s`는 물리 엔진에서 지난 시간이며 추론 대기 중에는 흐르지 않는다. 회차별 WebP 인코딩 비용은 배치 경과 시간에 포함한다.

`runs.csv`에 회차별 결과, `results.json`에 관측 좌표·후보·채점 결과, 회차별 JSON 파일에 모델 실행 기록과 물리·PaXini 로그를 남긴다. 같은 주황색 단일 물체와 관측 가능한 위치 범위를 사용한 기능 검증이다. 물체 인식 일반화나 모델의 인과적 효과를 평가하려면 동일한 장면과 후보에서 비교 정책을 실행해야 한다.
