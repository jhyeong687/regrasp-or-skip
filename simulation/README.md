# SO-ARM101 PaXini 집기 실험

저장소의 simulation 폴더에서 `python -m pip install -r requirements.txt` 후 `python sim.py --port 8770`를 실행하고 [로컬 대시보드](http://127.0.0.1:8770/)를 열면 됩니다. 렌더링까지 확인하려면 `python sim.py --verify`를 실행합니다.

## 오른쪽 화면에서 비교하기

- 첫 화면은 사각 블록을 든 8.90초 장면입니다. **집기 확대**를 누르면 양쪽 턱 사이와 물체가 크게 보여요.
- **4개 비교 재생**은 사각 블록, 원통, 미끄러운 블록, 무거운 블록을 같은 궤적으로 집어 봅니다. 모두 8.90초 결과를 표에 남깁니다. 물체를 바꾸거나 표에서 행을 누르면 해당 조건을 다시 볼 수 있습니다.
- 패드의 점은 누르는 힘을, 청록색 화살표는 표면 방향 힘을 보여줍니다. 점을 누르면 그 위치의 Fx, Fy, Fz를 확인할 수 있고 **현재 벡터 JSON**은 좌우 각 77점의 값을 저장합니다.
- 손목 깊이는 이 장면의 모델에서 195 mm부터 유효 처리합니다. **깊이 관측**을 누르면 접근 전 프레임을 볼 수 있습니다.

## 벡터 좌표와 실험 범위

- PaXini [PX-6AX GEN3](https://paxini.com/robot/ax/gen3)는 3축 분포 힘, 3축 합력, 3축 토크를 지원합니다. 이 실험은 [CP-M3025-Core 제품](https://mall.paxini.com/product/itpu/6894488c74e45ce616705b80?skuId=68946e6a74e45ce61670752a)의 측정점 77개 좌표를 사용합니다. 좌표 파일의 출처는 [paxini-sdk 모델 레지스트리](https://github.com/Jingyi-Z/paxini-sdk/blob/79c82145f88e158dd7706736e8c07f14f11cbd7a/paxini_sdk/data/pxsr_stdcp03b_points.json)입니다.
- `paxini_force_N`의 배열은 `[왼쪽·오른쪽][측정점][Fx, Fy, Fz]`입니다. 패드를 정면에서 보면 각 패드의 +X는 오른쪽, +Y는 위쪽입니다. Fz는 압축을 양수로 표시하는 리포트 값입니다. `pad_axes_world`의 각 회전행렬 열은 시뮬레이션 로컬 +X, +Y, +Z의 월드 방향이며, +Z는 패드 바깥쪽입니다. 월드 힘을 계산할 때 리포트 Fz의 부호를 반대로 사용합니다.
- MuJoCo 접촉력을 가장 가까운 측정점 세 개에 나눠 표시합니다. 접촉점 합력을 보존하며 화살표 표시 길이는 확대되어 있습니다. 실제 장착 센서의 방향 부호, 샘플링·양자화, 토크 출력, 소재 응답은 하드웨어로 검증할 항목입니다.
- 50 g 일반 블록과 600 g 블록의 그립 마찰계수는 0.8, 50 g 미끄러운 블록은 0.018입니다. 원통은 50 g, 그립 마찰계수 0.8입니다. 결과는 이 궤적과 모터 제한을 둔 한 번의 가상 비교입니다.

## 공개 시뮬레이터

여섯 구동 부품의 외형에는 단순 메시를 사용합니다. 패드 충돌 메시, 하중 모델, 관측 위치와 궤적을 유지했습니다.

## 접촉면 추정과 에이전트 데이터

- **접촉점 기반**은 MuJoCo 접촉력이 가까운 세 측정점에 나뉜 값입니다. **접촉면 추정**은 물체에 접촉력이 있을 때, 물체 표면까지의 거리가 0.4 mm 안에 있는 측정점에 힘을 다시 배분합니다. 두 표시의 합력은 같습니다. 접촉면 추정은 시뮬레이터 형상을 활용한 시각화입니다.
- `GET /agent_tactile`은 현재 프레임의 77점 배열, 합력, 센서 프레임 원점 기준 합토크, 측정점의 압력 중심, 접선/법선 비율, 약 100 ms 동안의 힘과 압력 중심 변화, 양쪽 접촉 여부와 하중 균형을 JSON으로 반환합니다. 힘과 토크의 평균 구간은 `tactile_average_window_s`에 표시됩니다. 응답에는 물체의 설정 질량·마찰·참 위치가 들어가지 않습니다.
- `센서 JSON`은 현재 프레임에서 두 촉각 지도를 함께 저장합니다. `../data/tactile-pilot.json`은 네 물체의 동작 중 주요 프레임을 담고 있습니다.
- 실제 보드 연동에서는 각 패드의 0점, 뉴턴 단위 및 축 부호를 먼저 확인합니다. 위치를 아는 접촉으로 측정점 순서를 대조하고, 힘을 뗀 구간과 살짝 미끄러지는 구간에서 시간 변화량을 비교합니다. 공개 커뮤니티 드라이버는 합력과 측정점 힘을 읽습니다. 해당 보드에서 토크를 어떻게 읽는지는 실물·펌웨어 확인이 필요합니다. 압력 중심 변화와 접선/법선 비율은 미끄러짐의 단서로 사용할 수 있습니다. [PaXini GEN3 개발자 자료 조회](https://paxini.com/cn/developer) · [paxini-sdk](https://github.com/Jingyi-Z/paxini-sdk)
